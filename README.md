# 🌱 Projeto Sucatas e Logística Reversa ♻️

## 🚀 Sobre o Projeto

Este projeto foi desenvolvido para ajudar pessoas a encontrarem pontos de coleta de sucatas e materiais recicláveis, facilitando o envio correto desses resíduos para empresas como a ArcelorMittal.

Nosso objetivo é incentivar a logística reversa, reduzir impactos ambientais e contribuir para um mundo mais sustentável 🌍💚.

---

## ✨ Funcionalidades

✅ Localização de pontos de coleta
✅ Informações sobre reciclagem ♻️
✅ Incentivo ao descarte correto 🗑️
✅ Conexão entre usuários e empresas recicladoras 🏭

---

## 🛠️ Tecnologias Utilizadas

💻 HTML
🎨 CSS
⚡ JavaScript

---

## 🌎 Objetivo

Promover a sustentabilidade, incentivar a reciclagem e apoiar práticas ambientais da ArcelorMittal através da tecnologia 💚♻️.
